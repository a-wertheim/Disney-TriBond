Letter Blitz

one letter, twelve categories, ninety seconds

Everybody needs a pen and a scrap of paper. The screen rolls a letter and shows a list of categories; you all race to write an answer for each one starting with that letter. When the clock runs out, we go down the list together — and an answer only scores if nobody else wrote it.

1

Roll

One letter for the whole round. J, Q, U, V, X, Y and Z sit this one out.

2

Scribble

Fill in as many categories as you can before the clock dies.

3

Compare

Read them out. Matching answers cancel each other. Odd ones win.
